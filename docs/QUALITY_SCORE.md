# Quality score

Grades each product domain and architectural layer, so the weakest parts are visible and improve on purpose. Update a row in the change that moves its grade.

## Scale
- **A**: specified, tested at its boundaries, docs verified, no open debt.
- **B**: works and is tested; small gaps listed.
- **C**: works, with known gaps in tests, docs or error handling.
- **D**: fragile or unspecified; changes here need extra care.
